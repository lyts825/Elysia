# Elysia 界面规范

v1.19.55 · 2026-10-23。原生 API 与 Agent 终端使用同一套视觉语言：低饱和玫瑰色、清晰的文字层次、稳定的操作位置。功能模块通过共享样式变量接入规范，保留独立页面和业务边界。

## 唯一基础来源

`apps/web/src/design-tokens.css` 定义基础颜色、字体、尺寸、圆角、阴影和动效。`style.css` 提供通用控件；功能CSS只负责模块布局和必要变体。避免在文件末尾叠加重复覆盖，直接调整所属规则。

| 类别 | 规范 |
| --- | --- |
| 字号 | 辅助12、说明13、正文/控件14、区块16、标题20/24、页面主标题32px；使用对应font变量 |
| 缩放 | 根字号100%，文字与主要间距使用rem，跟随浏览器字号和缩放 |
| 行高 | 标题1.3、紧凑控件1.45、正文1.65；代码与长文可有明确的阅读行高 |
| 字重 | 正文400，标签500/600，标题600/650；大标题使用轻微负字距 |
| 间距 | 4、8、12、16、20、24、32、40px，使用space变量；图形定位不机械取整 |
| 圆角 | 小标记6、控件10、卡片14、浮层20px，胶囊使用pill；圆点/仪表保留几何比例 |
| 控件 | 紧凑32、标准38、触摸44px；输入和选择框与标准按钮对齐，图标居中 |
| 阴影 | 小控件使用shadow-sm，菜单使用shadow-popover，弹窗使用shadow-panel |

## 控件与状态

- 主按钮用accent底与on-accent文字；次按钮使用surface底、明确边框；轻量操作用quiet/text按钮。危险操作使用danger，不能仅靠图标区别。
- 文本框、选择框和文本域统一边框、圆角与焦点；复选框/单选框保留原生语义。标签就近，说明使用辅助字号，错误使用danger。业务动作显式使用通用按钮类，选项卡、分页等专用控件由模块样式声明。
- 悬停、按下、选中、禁用分别处理。选中状态不被悬停覆盖；禁用元素不显示可执行按压反馈；键盘焦点保持可见。
- running/ready使用accent；waiting/verification使用warning；完成使用success；失败使用danger。状态文字与图标保留，不能仅依赖颜色。
- 弹窗共享标题、关闭位置、内容滚动与底部操作区。窄屏操作允许换行，内容滚动不隐藏最后一个按钮。菜单、选项卡和导航使用一致的选中背景。
- 会话、计划、工具、请求和任务卡片采用相同边框和间距。代码与Markdown保持内容自身的层次；长代码/表格在局部滚动，不撑宽页面。

## 长内容与复杂操作

- 工作流文本域和选择框使用独立的纵向字段布局，标签在上、控件占满可用宽度；复选选项保留横向标签。嵌入单项摘要不重复外层标题和边框。
- 分页的数量说明与翻页操作分组，窄屏按钮可分列；空列表显示0，不出现起点大于终点的范围。错误文字与重试按钮分行，长路径可以折行。
- 计划替换对照保留当前/导入两侧及差异文字标记，局部滚动区域可键盘聚焦；确认勾选和执行操作置于对照滚动区域之外。
- 交付核验使用摘要指标、逐文件状态与独立原因说明。临时下载和项目归档分别呈现，长文件路径完整换行。
- 预览内容保留最小阅读高度；短窗口和两倍缩放允许面板纵向滚动，关闭入口保持可达。长模型标识在内部换行，不能通过隐藏溢出掩盖裁剪。
- 弹窗中的欢迎说明使用普通信息区语义；只有实际独立弹窗声明dialog，避免干扰外层焦点循环和Esc关闭。
- 版本冲突对照区分“待选择”“已选择”“无冲突”，采用侧标记“将采用”；选择不等于已合并或已保存。三侧原文可独立聚焦和滚动，完整内容不截断。
- 草稿备份按摘要、包含内容、原文阅读、恢复确认分区，副本删除与恢复操作分开；不可读副本保留明确说明。已有确认条件继续决定控件是否可操作。
- 定时任务名称只在标题完整展示，操作按钮使用简短动词并通过可访问名称说明目标；状态、次数、时间分别呈现。模板长目标与约定保留键盘阅读区，历史分页就近显示页码与本页数量。
- 弹窗标题也必须处理长项目名和连续标识。操作失败提示若处于长列表之外，应滚入视野并获得焦点，保留错误语义；不能只有页面底部的不可见反馈。
- 模型连接导航中的名称与标识完整换行；窄屏使用有界滚动列表，选择及缩放后保持当前项可见。短窗口中的底部动作随内容滚动，不能占满编辑区。用户操作失败定位错误；初始及后台读取不抢焦点。
- 项目能力选项保持复选框与说明横向对齐，不能继承普通表单标签的纵向排版。记忆正文与来源分区、窄容器分行，当前、历史及待恢复内容分别命名；有界阅读区支持键盘聚焦和滚动，确认动作置于正文之外。
- 复用的上下文档位按所在容器宽度调整列数。短窗口允许弹窗整体滚动，关闭入口保持可见，并为固定标题预留焦点滚动空间；共享错误区支持长标识换行及键盘阅读。
- 本机能力预览将条目名称、来源、正文及继续读取分开；Skills、记忆和工具列表使用有界键盘阅读区，分页置于正文之外。扫描提示与失败分别使用警告和错误状态，完整展示来源路径及移除目标。
- 工作区管理的标签页采用单一Tab入口，方向键及Home/End切换；长标题不改变网格宽度。文件导航后焦点指向当前位置，路径、文档和源码提供完整键盘阅读入口，空筛选提供清除操作。
- 搜索输入自动读取时保留输入焦点；显式分页或重试完成后定位结果，失败定位错误。搜索失败与消息定位失败分别提示，关闭嵌入搜索后回到打开入口。重复同文案的操作失败仍需可见反馈。
- 终端运行面板按排队、运行、资源和暂时保留的资源分区；长任务名完整换行，资源说明明确“已预留 / 容量”。计时与最近输出时间置于实时播报区域之外，阶段与排队状态仍保留更新通知。
- 工具详情显式重试成功后返回已展开摘要，失败定位完整错误；若用户已转到其他控件，保留其当前焦点。长错误可键盘滚动，重试操作置于错误正文之外。原生可聚焦的代码滚动区保持浏览器行为，避免额外增加短内容的Tab停靠点。
- 终端连接与模板导航使用有界纵向列表，选择后定位编辑字段或标题；模型目录同时呈现名称与ID。未保存确认进入可滚动内容，短窗口允许整体滚动，避免确认栏或底部动作挤占编辑区。
- 诊断的配置来源、阶段状态、完整消息和修复入口分开；安装历史区分版本、状态、时间与恢复目标。长消息支持具名键盘阅读，动作置于正文之外；分页失败明确保留旧记录，不能显示尚未读取的页码。

- 维护计划按摘要、完整文件清单、注意事项和确认动作分区；确认操作置于阅读区之外。快照选择后显示完整名称、时间、占用、类型和标识，恢复与删除仍受当前资格约束。
- 续接消息使用简短选择标签，并单独提供具名正文阅读区；选择状态同时用文字和颜色表示。会话能力、读取失败和失效选择分别呈现，保留正文、原请求重试与消息数量限制。

- 通信消息将完整来源标题与简短导航动作分开。显式分页、搜索或重试完成后定位结果或错误，空结果也有可读焦点；用户已移焦、点击其他位置或离开窗口时放弃待执行的焦点移动。关闭处置草稿返回原入口，取消与迟到响应不能覆盖当前内容。

- 任务中心区分列表读取失败与单个任务打开失败。行内问题提供独立阅读区，打开失败就近反馈；搜索和项目筛选显示字段标签及当前项目完整名称。短窗口允许内容与分页整体滚动。
- 会话操作弹窗使用简短操作标题，完整对象名称单独呈现；页脚复用共享控件。窄屏导航展开时，操作弹窗必须位于导航之上，不能被不可交互的侧栏遮挡。
- 模型浮层根据锚点上下的可用空间定位。极短窗口改为视口内滚动，标题、关闭与完成动作均可到达；窗口及内容尺寸改变后重新定位。终端模板选择保留完整名称阅读入口。

- 任务配置的完整目标与项目名称独立呈现；长权限、资料和模型信息使用具名键盘阅读区。交付要求逐字段显示数量和超限说明，短窗口中的正文与底部操作可整体滚动。
- 项目交付物与验收标准显示数量，正文使用独立键盘阅读区；候选确认与阅读内容分开。关联执行显示本页数量和页码，空搜索可清除并返回输入框。
- 产物变化以前后版本卡片对照，名称、格式、核验状态与完整标识分区。变更明细使用中性底色，避免继承外层通过状态；长错误与重试操作分开，关闭当前预览返回原入口。
- 历史复核标明当前已读记录；列表、完整备注、原标准和版本来源分别阅读。用户可主动定位已读详情，异步完成保留当前焦点；读取历史不改变当前交付结论。
- 执行拓扑以阶段列表组织任务卡片，状态同时显示颜色和文字。任务全名及依赖清单可独立阅读，恢复入口关联对应任务；记录不完整时仅标明已读任务，不推断完整进度。
- 恢复界面分开呈现依赖来源、完整路径、定位操作及重复错误。禁用恢复按钮就近显示原因，并关联相应说明；长工具名称和错误码完整保留，原执行资格决定操作是否可用。

- 任务约定按目标、范围资料、交付验收、约束假设及审计预算分组；切换模型显示完整任务与前后配置。短窗口允许正文和动作整体滚动，同模型确认仍使用独立明确操作。
- 完整记录的列表、摘要、完整标识和 JSON 正文分层。摘要可收敛高度，展开后完整内容仍可键盘阅读；错误正文与重试分开，分页保留读取中状态和当前范围。

- 角色模型按执行与复核分别显示完整选择信息。当前配置与草稿对照保留各自版本，读取、保存及草稿问题分别反馈；卡片按实际容器宽度排布。
- 来源与修订的完整标题、状态和打开操作分别呈现，缺失来源保留快照说明。分页以成功读取结果为准；翻页失败保留旧页，禁止复用旧页游标继续向后翻页。

- 旧备注的标准、原文、当前目标及合并预览分别阅读，单选标签保持简短且支持方向键。阅读不改变选择，取消回原入口，成功追加回到列表摘要，原字数及版本条件保持。
- 长计划编辑提供有界交付项索引，定位对应名称字段。新增聚焦新项，移除定位相邻项，空列表回到添加入口；数量说明与保存操作分区。

- 项目待办使用紧凑的语义分类计数，完整名称、阻塞原因和下一步动作分区；动作关联对应目标，长内容可用键盘阅读。
- 冻结清单的交付项和产物使用简短选择标签，完整名称、版本、元数据与选择动作分开；历史标明当前选择，冻结依据、当前记录状态与全部校验信息独立阅读。

- 续接材料区分待加入与已加入备注，短勾选标签与完整来源正文分开；差异修改按状态、产物名称、版本对照与具体要求组织，正文阅读、编辑和确认各自独立。

- 复验证据的短选择标签与说明、完整引用、证据哈希及产物哈希分开。列表支持有界键盘阅读，数量、跨页选择与冻结条件就近说明，阅读正文不改变选择。

- 原意见复验分别呈现原始意见、已保存结论与当前编辑草稿；证据说明、引用和核对信息完整保留。状态与只读原因使用文字说明，保存、放弃及版本确认置于长正文之外。

- 项目默认配置分别显示已保存版本与当前表单摘要，模型、计划、上下文、预算和并发使用语义字段。展开阅读不触发载入或保存；初次自动载入、手动重读与草稿保留条件继续由原业务决定。

- 逐项验收的短标题、标准原文、已读证据和分页分别呈现。本页数量与总量就近说明；完整阅读区具名且支持键盘，读取失效仍保留旧内容并明确重读入口。

- 用户复核的结论状态与编辑草稿分别显示。整体及逐项备注标明字数和数量限制；旧标准与旧备注独立阅读，保存、读取和冲突状态就近说明。

- 原复核弹窗分开呈现任务保留的备注快照与原只读记录。重读时明确保留上次已读内容；快照和错误支持完整键盘阅读，重试与关闭操作独立可达。

- 来源备注按原标准、完整正文和版本来源分层。复用正文沿用外层阅读区，已加入列表的查看与移除动作置于正文之外，并使用明确的目标名称。

- 项目创建草稿区分依据与当前的计划及标准版本。完整名称、保留要求、合并选择和后续创建动作分层；对齐版本仅表示草稿依据已更新，创建仍需明确执行。

- 从交付项创建任务时，完整来源、计划与标准版本、恢复提示和可编辑目标分别呈现。字数说明关联输入，缓存失败显示完整问题；读取失败也使用标准可滚动弹窗正文。

- 保存文件包以紧凑字段显示项目总量、本页条目、大小和时间。完整名称用于标题及动作目标说明，文件包与冻结清单的独立哈希完整保留。删除和集合确认说明置于阅读区外，未知读取结果不能呈现为零。

- 交接确认分别计数已加入与待加入材料，忽略开关使用短标签并关联具体影响。审计模型开关与说明保持横向对齐，二次确认明确适用范围，原明确同意条件保持。

- 订阅连接的原生选择框之外提供当前账号和型号的完整名称与标识，登录、订阅授权和额度状态分别说明。模型说明可展开，完整反馈可键盘阅读，显式失败沿用现有焦点策略。

- 交付文件使用短预览和下载动作，并提供明确的完整名称及核验信息入口。嵌入证据的元数据复用证据阅读区；关闭预览仅在操作仍拥有焦点时返回可见入口，用户已移焦或入口不可用时放弃恢复。

- 终端连接的验证状态、完整说明和检查时间分别呈现；目录及所选模型保留完整名称与标识。显式失败反馈沿用原焦点策略，后台读取失败不抢焦点。

- 终端安装失败的分类说明与原始记录分别呈现，修复动作关联具体问题。中断核验将说明输入、字数、两类结果影响和提交操作分开，保留原显式核验门槛。

- 终端配置表单按运行环境、高级字段、当前摘要和检查反馈分组；摘要名称与实际展示字段一致。长命令与反馈提供完整键盘阅读入口，检查、保存和关闭沿用原条件。

- 终端模板管理分别展示编辑依据、当前草稿、当前编辑和新任务默认状态。模板摘要与子表单使用独占类名，防止级联覆盖；连接来源区分继承、环境变量、指定连接及无目录。

- 订阅连接的环境、账号与所选型号分别提供完整阅读。就绪说明直接依据原资格判断；设备码、型号说明和额度长名称不撑宽布局，未知额度不能显示为零。

- 项目用量的项目汇总与本页任务明细明确区分，统计版本和完整连接来源独立阅读。费用展开不改变计算；翻页失败保留已读页码与旧结果提示。

- 任务列表序号明确为本页范围，完整名称与执行、复核状态分别呈现；读取问题与关联动作关联。所属样式迁移时保留其他宿主复用的基础规则与响应条件。

- 推理字符数仅说明当前已显示内容，不推断完整总量，并置于实时播报区域之外。完整正文与错误分别阅读，重试置于错误正文之外，保留流式更新时的选择和阅读位置。

- 工作区主页的完整项目名与欢迎语分开，目标有可见标签，模型摘要保留完整连接与型号。输入区按容器宽度调整，样式限定在主页内；归档和未就绪状态就近解释。

- 工作入口菜单高度受视口约束，菜单内部滚动不关闭浮层。当前项有独立 Tab 入口，方向键与 Home/End 移动，Tab 退出到相邻控件，Esc 返回入口；选中背景不被悬停覆盖。

- 文件分页区分当前片段与完整文件大小，精确字节说明明确起点包含、终点不包含。位置字段提供可见标签与末页说明，窄容器动作可换行，保留编码边界对齐行为。

- 文件内容说明编码来源与当前已读范围，字符数不能作为文件字节数。源码与文档往返时按客户端、阅读键和节点恢复位置；同一节点的正文更新保留当前位置，就绪前不写入旧滚动状态。

- 产物日志的完整匹配正文与短定位动作分开，位置明确使用字节与终点不含边界。能力、搜索和文件读取分别反馈，待取时说明保留旧片段，重试置于错误正文之外。

- 启动设置区分草稿预览与保存结果，行为、文字颜色及媒体文件分别呈现。最近启动耗时按记录折叠，阶段时间保留完整值，读取失败说明旧记录是否仍保留；短窗口可整体滚动。

- 本机能力的候选名称、来源与说明置于选择标签之外，阅读不改变选择；已同步状态和读取动作分开，完整来源保留键盘入口。嵌套折叠内容的事件必须按目标归属处理，展开单条记录不触发外层重新读取。

- 执行确认分别核对模型、权限、写入范围与授权网页，优先呈现名称和型号。默认差异说明只覆盖实际比较字段；纯空白资料和零项授权不能标为已填写，原创建条件保持。

- 项目与会话侧栏的标题与状态信息分层，执行、只读、置顶、草稿和未读均有文字说明。标题保留完整名称语义，导航行内不增加独立滚动区，元数据按容器空间换行。

- 预览停靠面板的完整产物元数据沿用产物区整体滚动，避免挤占正文。历史读取失败与空状态分别呈现，重试和下载独立可达；宽度调整与阅读恢复沿用原规则。

- 工作区预览的完整任务、模型与文件信息可主动展开，未读取模型绑定时不能以连接标识冒充型号。筛选无结果保留当前预览，并提供清除入口；资源不完整用警告状态，读取失败单独反馈。

- 模型切换状态区分当前选择一致、未就绪、可应用、限制与忙碌，可应用不等于已保存。连接标识和版本通过独立入口核对，绑定快照版本与当前目录版本分别命名，主要型号优先可见。

## 可访问性与维护

核心文字与对应背景对比至少4.5:1。辅助说明不以降低透明度替代可读的颜色；用户自定义启动背景按亮度选择文字色。减少动效使用静态状态，增强对比度提高边框和文字区分。供应商标志色只表示身份，不替代状态文字。

新增界面必须复用上述变量与控件。验收检查桌面、窄屏、放大文字或2倍缩放、长中文、键盘、禁用和错误状态；关注被overflow隐藏的内容，不能只以页面没有滚动条判定合格。实际验证结果与未覆盖范围记录在EXECUTION.md；测试材料保留本地忽略目录。
