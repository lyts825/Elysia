# Elysia

本机多 Agent 协作应用。文件修改、资料分析与办公产物使用统一项目和任务入口，接入 OpenAI Responses 与 DeepSeek Chat。模型按需加载办公技能，无需选择 Code / Work 分类。

当前源码为 **v1.14.0 本地版本**。左上角切换 **Elysia（原生 API）** 与 **Agent 终端**，保留各自页面、草稿和预览，隐藏入口暂停事件流与轮询，并取消过期读取；相同读取合并，GET 超时可明确重试，配置失败不阻塞对话列表。Codex CLI 和 DSH 默认预设，其他 CLI 可按需启用。终端管理提供安装历史、独立 API 连接、诊断直达修复、能力说明和数据维护；连接验证与模型目录分别保存安全状态和时间，配置变更后提示重新检查。执行状态显示排队原因、阶段与资源占用，轻量、标准、大型规格在创建任务时冻结。会话、请求、操作和产物按页读取，完整用量统计独立计算。续接需求与核验说明自动保存，同一窗口刷新可恢复有效的预览阅读位置；文件链接支持源码行号和跨页标题定位。可靠 Codex 会话可显式备份及恢复当前检查点，快照历史支持搜索、分页、当前资格说明和预览后确认删除；恢复前保留原文件，不自动启动任务。任务保留创建时的权限、连接和累计运行限制，旧 Docker 任务保持只读，详见 [Agent 终端架构与使用](docs/AGENT_TERMINALS.md)。v1.0.0-preview.1 已使用 Codex 订阅和 DeepSeek API 验证项目交付项、人工确认、冻结导出及重开流程，正式窗口未重载；真实 Docker、固定 CLI 镜像及其他供应商验收保持独立记录，终端只读计划及未观测用量不被标记为已支持。范围、进度与验收结论以 [执行文档](docs/EXECUTION.md) 为准。

v1.9.0 参考 [PilotDeck](https://github.com/OpenBMB/PilotDeck) 的工作区能力、白盒记忆和上下文管理思路，加入三个原生项目功能：

- 项目工作台的“项目能力与记忆”：选择技能、导入记忆及 MCP；新任务保存当时的正文与配置，之后新增能力不会自动扩入旧任务。全局停用或删除仍可收紧已有任务。旧项目未配置时保持原有选择，新任务同样生成快照，最多 2 MiB，超限明确拒绝。
- 项目记忆可查看来源、版本和历史，支持编辑、撤销及恢复。只有启用的记忆供所属项目按需读取；最多 100 条，正文每条 16 KiB，每条含历史最多 128 KiB / 20 个旧版本，超限仅淘汰最旧完整版本。
- “上下文窗口”中的“长任务工作状态”：暂停到安全检查点后，读取并核对当前要求，再明确批准。压缩只收起批准范围内较早历史，后续更正和最近完整交互保留，原文可回查；撤销后恢复原压缩方式。角色模型可在项目面板设置，执行与复核连接在新任务创建时冻结，显式选择优先；连接修订变化后须重新选择，原累计预算继续约束。

能力、记忆、角色模型和工作状态输入沿用本机草稿恢复、版本冲突核对及同请求重试。上述能力尚未经过本版真实供应商多代理验收。

v1.10.0 继续加入受控定时任务、统一使用前检查和 Windows 便携分发：

- 原生项目工作台的“项目定时任务”可复用不带附件、文件快照或转交来源的任务。先读取来源模板并保存草稿，再核对完整约定、权限、预算、间隔、次数和截止时间后启用。默认到期创建暂停任务，用户启动后才生成计划；自动执行另需明确勾选。每项目最多20条、全机100条，间隔至少5分钟、累计最多100次、期限最多31天、每次最多1M Token，原任务预算及执行限制继续生效。
- 调度只在本机服务运行期间检查，不补跑停机错过的时段；上次任务尚未完成则跳过。模型、项目目录、能力、启用记忆或角色路由变化，以及上次任务失败、取消或待核验时，调度暂停并说明原因，重新核对不会清零累计次数。暂停或删除定时任务只影响后续创建，已创建任务在任务内单独停止。
- 侧栏“首次使用检查”汇总模型、项目及当前终端入口的已保存状态，可直接进入相应管理区域。历史验证不等同于当前可用；检查不读取密钥、不访问网络、不自动安装或调用模型。读取失败、取消和迟到响应保留上次结果及输入。
- Windows x64 便携 ZIP 包含 Electron、Node、生产依赖与预构建页面，解压后启动 `Elysia.exe`；用户无需安装开发依赖。包内附版本、文件 SHA-256、第三方许可和完整性核验入口。当前是未签名本地构建，未公开发布。

本版数据格式为 schema8，最低读取版本1.10.0。首次打开旧数据沿用双入口先备份再升级，schema7备份仍声明最低读取1.9.0；回退旧程序应先恢复升级前备份。

v1.10.1 改善日常运行：调度器按下次到期时间安排检查，未到期时不开写事务，到期仍核对最新配置及权限。暂停或启用调度后保留表单中的未保存编辑，刷新、模板重读或记录版本变化后重新确认删除。Windows 分发和启动校验改为按固定大小分块计算文件 SHA-256，避免一次把整个运行时或 ZIP 读入内存；核验结果和数据格式保持一致。

v1.11.0 补齐配置处理和调度追溯：从“首次使用检查”的具体模型、连接或模板进入管理时，直接定位对应配置；目标已删除或尚未读到时明确提示，迟到读取不覆盖手动选择及未保存编辑，不自动验证。每条定时任务可显式展开“创建历史”，每页最多20条，查看精确关联的任务当前状态并打开任务；刷新、翻页和取消均保留上次成功结果。历史依据已保存的调度记录，删除任务时相关记录也会清理，因此缺失或损坏部分明确标为历史不完整，不凭标题或时间还原归属。查看历史不修改调度设置或启动任务。

v1.12.0 改进 Harness 的授权内自主执行：模型每步接收由当前授权、阶段、角色和实际工具生成的执行策略，已接受计划不会再被描述为等待批准；常规实现、可逆修复和必要验证直接推进。普通补充默认保留原计划与子任务，需作废旧计划时可主动选择“重新规划”；暂停、待核验和累计限制继续有效。完整模型响应中的可修正 JSON 参数错误交回工具网关，并提供具体纠错建议，模型可在同任务内修正后继续，不自动重放未知副作用。原生模型与终端任务共享简短自主执行指导，新建任务不会再无条件把用户明确要求的发布列为禁止事项；实际权限与明确对外授权仍由原流程约束。

v1.12.1 修复连续执行与恢复：原生工具调用按所属模型响应区分，后续响应复用调用 ID 也会执行本步动作；重放只返回本次已记录的操作结果，旧记录归属不明时明确等待核验。命令、产物登记和 MCP 等批次按顺序执行，独立读取保持并发。原生补充消息保存完整发送回执，响应丢失后核对原命令，避免重复补充或重复作废计划；运行时提醒按历史记录有界压缩，用户要求及完整原文保留。

v1.12.2 让当前澄清问题独立于最近100条进度读取：长事件流中仍可查看和定位各代理尚待回答的问题，回答或取消后不再显示旧问题。问题及近期进度的损坏、超限记录分别提示，其他可读内容继续显示；损坏进度的推送降级为刷新通知，避免中断服务。输入草稿和原发送回执保留，重新读取以新结果替换同一条进度，快速切换任务也不会被迟到的问题定位抢走焦点。

v1.13.0 在原生会话中分区展示供应商返回的思考记录：生成时显示状态和简短预览，默认折叠，展开后可阅读、继续加载及复制已显示内容。流式更新保留用户的展开、滚动和文字选择，同一请求完成后衔接历史记录；思考阶段中断也可回读已保存片段。历史正文按需分页，单次展示最多256Ki个UTF-16字符，达到上限会提示，原始思考和模型回放保持完整。当前接入DeepSeek公开reasoning_content；未返回思考文本的模型仍按原流程展示回答。

v1.14.0 在每轮模型回复中明确列出“操作过程”和工具调用项，显示中文动作、原始工具名、目标及独立状态。展开一次即可核对输入、结果和错误；折叠时保持摘要，完整详情按需读取。等待结果或待核验不会冒充成功，缺少记录不再断言未执行；完整业务参数和结果保留原始字段，调用编号仅表示请求项顺序。

原生项目首页现为**项目交付工作台**。先填写目标、范围、不做事项与可验收的交付项，再从交付项创建任务，或明确关联已有执行；一个交付项可保留多次尝试，由用户选择当前候选。创建前仍核对模型、权限与预算，项目定义不会改写旧任务约定。执行完成、人工采纳、来源意见复验和符合当前项目标准的确认分别保存；修改某项标准或候选结果后，该项旧确认失效。项目首页按必需项优先显示待办、具体阻塞原因和直接处理入口。项目计划和创建输入保留草稿；计划变化后对照原始基线、当前计划与本人输入，无冲突字段合并，冲突逐项选择后再保存。旧草稿没有基线时明确核对，不推断覆盖。独立聊天及 Agent 终端保留原入口。

在“编辑目标与交付计划”中可复用计划：导出当前编辑草稿为 version 1 JSON，或读取文件、预览并明确应用到当前编辑草稿，再按正常流程保存。预览对照当前草稿与导入计划的目标、范围、不做事项和全部交付项；不按同名项配对或合并，文字一致的交付项也生成新编号，需重新关联任务并确认。原任务、复核、冻结清单和保存包不迁移。接受最大192 KiB、最多40项的有效UTF-8文件，未知版本、额外字段、损坏和超限内容直接拒绝。确认绑定正在核对的草稿和文件，编辑后需重新勾选。预览同时按实际保存规则计算新稿与完整原稿备份的总容量，超过200000字符时禁用应用，保留原稿和预览，可先下载完整工作台原稿TXT。应用前原稿随工作台草稿保存，返回或重开后仍可恢复；保存成功才清除备份，保存冲突继续保留输入并按原基线核对。

工作台另有“草稿备份与恢复”：导出绑定当前项目、入口和工作台数据范围的JSON，读取后查看完整草稿，再明确恢复到本机输入。最大640 KiB有效UTF-8文件、内部草稿200000字符，未知版本、额外字段、损坏或不匹配来源拒绝恢复；TXT仍用于查看原文，跨项目复用使用计划JSON。恢复前先完整保留当前原稿并读回核验，同来源多个窗口的恢复串行处理，原稿变化、存储不足或缺少安全恢复锁时拒绝覆盖。已有不同保护副本需另存并明确替换。恢复仅改草稿，保存仍校验当前缓存及项目版本，旧任务和清单引用须核对，不自动执行。保护副本只在当前浏览器同来源保留一份，不属于服务端或全量备份；跨端口、不同来源重开时应另存绑定JSON。未应用的计划导入预览临时保留，返回或切换工作台页面时提示是否离开，编辑稿和已应用的原稿备份继续保留。

产物元数据、冻结清单历史和已保存文件包列表只在读取成功后推进页码，读取中、取消或失败保留上次成功页并标明旧结果；可明确重试本次目标，上一页仍从已成功位置返回。折叠产物选择会取消在途读取，重开从已成功页核对，已有选择保持。恢复前副本直接显示时间与完整 JSON 文件大小，可先另存并确认后删除当前项目的副本；另一窗口改变副本或存储结果无法确认时要求重新核对，不修改当前草稿。恢复等待其他窗口释放锁时可原地取消，预览保留；已开始的恢复不提供撤销承诺。

工作台分别显示读取、保存和打开问题：后台刷新只清读取问题；保存提示绑定操作路径与方法，仅同操作成功或明确核对后清除。打开失败不把有效统计标为未知，真正读取失败或取消保留旧状态提示。项目执行列表在服务端分页前筛选任务，搜索和总数使用同一范围，聊天不占任务页面；任务中心未指定 kind 时保持原混合行为，损坏或未知归属继续显示缺口。未应用计划导入预览的离开确认覆盖侧栏项目、对话及任务中心实际跳转，取消保留原页面和来源弹窗状态；普通打开弹窗不提示，创建提交在确认后执行。副本删除等待也可原地取消，尚未执行删除时保留另存确认与预览，进入核对删除阶段后不提供撤销。

“草稿保存与恢复”分别显示本机服务保存状态和浏览器恢复保护结果；浏览器存储禁用、空间不足或读回失败时明确标记仅能确认当前窗口内存中的内容，并可导出未保存原稿。保存问题按草稿逐项处理：连接失败可重试，版本冲突先对照当前窗口与服务端完整内容，再明确保存所选项；采用服务端内容前先另存本地原稿并确认。重试会先核对服务端，核对后内容再变化仍要求重新处理，不批量覆盖其他冲突。浏览器副本仍限当前来源和窗口，导出的未保存原稿用于保留及人工核对。冻结交付前逐项列出目标、名称、选择和候选状态的阻塞，并定位处理入口；读取失败显示条件未知，服务端继续最终核验。

项目工作台增加“项目用量”：显式读取原生项目内全部任务和对话的请求次数、已报告Token、预留及未知状态，按请求当时冻结的订阅/API连接与模型分组，可分页查看任务并直接打开。费用使用请求保存的用量和当时价格估算，USD/CNY分别累计，未结算、缺少用量或价格的记录明确保留缺口；不会用当前配置重新计价，也不把订阅未知费用算作零。首次读取、刷新和翻页均可主动取消，保留最后成功的汇总及页码，不自动重新读取；可明确重试本次读取或刷新。读取中、取消和失败均标明上次结果，翻页成功后才推进位置，统计变化要求重读。切换项目隔离过期响应，不自动调用模型。

旧请求账本首次统计按32条短事务补建读取投影，逐条损坏隔离和取消检查保持；失败只回滚当前批，已处理批次可供重试复用，原请求正文及版本不改写。v1.1.0核心读取对照中，10k × 4 KiB从33.79秒降至6.19秒，10k × 64 KiB从35.57秒降至8.42秒；v1.2.0进一步复用请求投影的更新语句，减少完整服务入口逐条编译SQL的开销，同一原界面夹具完整HTTP首读从14.06秒降至4.94秒。各项计时口径分别记录，不混用核心读取和完整界面耗时。结果来自本机隔离数据，不代表所有硬件或数据规模均满足15秒读取期限；单条同步解压仍不能中断。

在“汇总交付”中明确选择已就绪的交付项及产物元数据，纳入全部必需项后冻结交付清单。清单保存当时的项目目标、标准、选定任务、采纳意见、人工确认及来源复验依据，可下载 JSON 或可读 Markdown。冻结后源任务的修改或删除不改写快照；删除整个项目会删除该项目清单，应先导出需要保留的交付记录。界面另行显示当前任务与产物记录是否仍一致；元数据状态不保证文件正文可读。最多40个交付项、每项200次关联尝试，单份冻结清单最多8 MiB，超限拒绝而不截断。当前交付为本地版本，公开发布与终端实验能力验收另行记录。

清单详情可显式“检查交付文件”，查看每份所选正文的完整性、大小和包内位置，再下载最多64 MiB的实际文件交付包（ZIP）。包内包含原始文件、JSON/Markdown冻结清单、说明及SHA-256索引，可复制到其他目录独立读取；仅打包所选文件，不自动补齐应用依赖。检查与下载均核验冻结版本，缺失、变化、损坏或超限会阻止完整打包。核验、准备和发送分别显示进度，长任务使用短状态读取避免总时长超时。生成和读取可取消，刷新后同一窗口重试释放旧作业；其他窗口保持独立。失败不会登记新的成功交付，下载重试重新核验。新作业拥有独立临时目录及所属标记，重启仅回收确认孤立且归属完整的目录；未知和活跃目录保留。清单本身仍只保存元数据，不会自动永久保留来源正文，需在删除源任务或项目之前下载文件包。

清单详情另有“保存到项目”：每份冻结清单可显式保存一份最多64MiB的已核验ZIP，完成落盘及记录提交后才显示已保存。保存包不依赖源任务，删除来源、重启或执行对象维护后仍可独立下载并核对SHA-256；本机保存包随全量备份和恢复验证，不等于已经复制到外部备份。汇总交付列出保存时间、大小和下载入口，可明确移除保存记录；共享正文留待对象维护回收。删除项目会删除保存记录，须先查看/导出并确认当前完整保存集合，读取失败或集合变化时拒绝删除。下载临时文件包与保存到项目是分别操作，移除记录不改写冻结清单。

原生任务支持交付复核：按验收项查看文件、产物和命令证据，可打开预览并基于选定内容创建修订任务。独立聊天可选取消息和产物转为项目执行，创建前重新确认目标、权限和预算；新任务保存来源版本与哈希，旧对话继续保留。最多选择10条消息和10份产物，正文与说明合计16 KiB，每份产物8 MiB、合计32 MiB。模型可分页读取来源文本；有写入授权时可显式把选中的原始文件复制到任务工作区，二进制资料也可继续处理。

交付和差异读取使用可重建的七字段产物元数据，现代记录首次读取不再逐份解压产物正文；旧库首次需要回填，后续复用。读取仍绑定原始版本与指纹，原始数据改变、损坏或跨连接修复时失效重建。维护扫描增加取消检查点，确认仍处于只读扫描时可受控停止工作线程，核验和删除阶段保持协作退出及真实审计。

旧库交付读取、复核详情、产物差异与项目状态先分批准备产物记录，显示已处理数量，完成后再读取完整结果。可以取消当前窗口的准备，其他窗口继续读取；已处理记录和历史原文保留，显式刷新可继续。用量页在统计版本未变时复用汇总，数据变化仍要求重读。删除任务使用可重建引用投影，避免重复展开无关历史，共享和嵌套对象保留；旧数据第一次回收需回填引用，无法核验仍被引用的压缩对象时停止并回滚删除。

已准备好的项目直接完成读取准备，其他项目正在回填时仍可读取。工作台正常后台刷新保留当前内容，不反复显示准备提示；首次进入、手动刷新及确实需要回填时仍显示读取状态，回填可单独取消。

保存包可直接“查看冻结依据”，查看对应清单当时的项目标准与复核意见，冻结时间和保存时间分别展示。同名文件包按各自清单定位，来源任务删除后仍可查证；重读失败保留所选清单和已读内容，并明确当前来源状态未确认。

产物变化可逐条填写要求并加入修订清单，待选内容与已加入内容分别保存；交付变化后须重新核对再创建。最多选择20条差异，要求合计16 KiB、包含历史与当前元数据的快照合计32 KiB；已移除项只有历史元数据，文件正文仍须另行明确选择。修订完成后，可逐条对照原意见，手工选择本次标准和证据，登记“待复验、已解决、仍需修改”；执行完成或采纳交付不会自动解决原意见。交付变化后旧复验标为过期，分支与后续修订各自保存结论。未关联旧备注可手工选择当前标准或转为整体备注，先预览追加内容，保留目标已有文字和原备注。

交付后可记录“已采纳”或“需修改”及逐项备注，复核与执行完成分别保存；标准、结果或产物版本变化会使旧结论失效，并显示变化涉及的内容。完成页显示复核状态，任务中心可独立筛选“未复核、已采纳、需修改、需重新复核”并直达复核。未保存备注保留为本机草稿，保存冲突后可重读并重新决定；创建修订时可逐条选择已保存、本机未保存或历史备注，完整原文与原验收标准作为独立来源保存，不占用修改意见额度。待选与已加入内容分别恢复，创建前须返回处理待选内容或明确忽略，只有明确加入的内容提交；可仅凭备注创建修订。最多带入40条备注，备注正文合计16 KiB、包含原标准的快照合计32 KiB，超限提示减少选择，不截断原文。来源交付变化后须重新核对并明确确认。复核历史从v0.27.0开始逐次保留，可分页读取原文与变化说明；旧版仅回填仍存活的最后结论，原标准或基线缺失明确显示未知。交付读取失败时仍可独立查阅复核历史；损坏或未知格式的比较基线显示无法比较。来源链和直接后续修订支持双向定位及分页，删除来源后仍保留已捕获快照。已保存备注可按来源任务和复核记录直达原复核；原记录不存在时仍展示本任务保留的备注。产物变化明细每页20项，显示复核时与当前名称、版本及哈希，可打开当前产物；已移除产物只展示历史元数据。翻页期间交付变化会要求重读，避免混合不同版本。创建原生任务可填写具体交付物与验收标准，直接执行要求至少各一项；有效项目默认会进入紧凑确认，仍需核对本次权限、预算并明确创建。

项目可保存原生默认模型、思考强度、上下文、计划模式、预算与并发，新建任务时带入且可修改；失效连接和版本冲突会明确提示，已有任务保持冻结配置。流式正文改为SQLite增量分块保存，先持久化再显示，减少长响应反复压缩整个请求的开销。新增表包含尚未结束的响应正文，回退旧客户端必须使用升级前备份。

失败或暂停的依赖会显示来源链，可定位并单独恢复失败分支，已完成分支保留。相同确定性工具错误在没有进展时先提示纠正，再暂停等待处理；正常轮询、限流和结果不确定的操作沿用各自恢复规则。运行提醒与用户原话区分，来源选择不会混入新的内部提醒。验收项和各项证据分别分页，显示完整计数；交付记录变化时要求重新读取，避免把未加载证据当作缺失。

数据格式升级为 schema v7，最低读取版本为 1.9.0，旧客户端拒绝打开新库，避免绕过项目能力限制。启动继续先备份再迁移；schema6 旧备份保持最低读取版本 1.0.0-preview.6，schema5 保持 1.0.0-preview.1。备份记录应用版本、封装格式、各入口数据格式与最低读取版本，恢复保留旧格式兼容并拒绝未知格式；回退到旧应用应使用升级前备份。请求预算与账号限流继续使用原账本，保留原用量、未知预留和重试语义。

普通创建配置按入口和项目保存草稿；修改目标、切换项目和刷新后可恢复，提交前重新核对模型、权限和预算。保存冲突保留当前输入，明确重试后才覆盖；创建成功只清除实际提交的草稿。来源正文与修订说明统一按UTF-8计数，界面显示16KiB余量。

桌面启动先取得单实例锁，再构建并使用独立版本目录中的前后端及内置提示词/技能；重复打开只聚焦已有窗口，不覆盖正在使用的页面资源。缺少Electron时先执行 `pnpm install --frozen-lockfile`。数据库升级先取得两个入口的锁，验证旧格式备份，再迁移副本并安装；中断恢复按安装记录完成回滚或收尾。工作区保持原位，升级前备份保留在数据目录的 `backups/before-upgrade-*`；回退旧客户端仍应使用升级前备份。

界面采用紧凑会话布局：首发与续聊输入框统一尺寸，模型与上下文控件按实际对话区域宽度适配，空列表不显示无用分页。侧栏“本机能力”管理 Skills、记忆与 MCP；同步扫描采用紧凑表单，详细说明按需展开。上下文详情优先显示占用和剩余空间，实际用量与预留可展开；低高度导航、长标题与窄屏弹窗经过隔离预览验证。

顶部“任务中心”支持状态、项目和标题筛选，按页查看当前入口的任务；待回应定位到回答位置，待核验打开对应操作，终端操作进入专用核验面板。两个入口各自保留筛选。桌面状态通知默认关闭，启用后隐藏入口也可报告新的完成、待回应、核验或失败状态，不补发历史记录；通知点击切换所属入口并定位对应会话。通知使用有界队列和有限重试，发送前复核当前状态，失败只显示数量与时间。对话工具栏“搜索正文”每页返回20条短片段，点击后按目标读取附近最多40条消息；同窗口切换或刷新可恢复阅读锚，最多保留50个会话，不保存正文。失效阅读位置会明确提示并返回最新消息。搜索共用在途工作，取消无订阅者的读取，增量索引及分批扫描减少重复解压；持续更新或繁忙时可明确重试。

侧栏“外观与启动”可预览并保存开屏样式、标题、说明和配色，或导入最大 4 MiB 的 GIF / MP4 / WebM。开屏可关闭或跳过，遵循系统减少动态效果；本机服务及认证就绪即进入会话界面，不等待动画播放。桌面启动外观为本机窗口级设置，两个入口共用；浏览器保存于当前来源。动画覆盖 Electron 窗口开始显示到连接完成，首次依赖安装或源码编译仍由启动器完成。媒体独立保存在本机资产或浏览器 IndexedDB，仅播放与预览时读取；损坏或不支持的媒体会显示错误，保存失败保留原设置。外观设置中的“启动记录”显示最近20次的阶段耗时，区分缓存构建与重新构建，不记录项目内容或凭据。历史首屏读取 30 个会话、40 条消息，滚动后按需追加，保留阅读位置；窗口达到 300 个会话或 240 条消息后，可手动切换更早段落。固定与当前选中会话仍单独保留，搜索使用完整目标内容；完整统计、上下文设置和项目会话数按需读取；输入区实时预览独立读取，项目元数据迟到不阻塞历史列表或覆盖新输入。

本轮修复启动后的草稿恢复和迟到导航：首次草稿读取失败时，仍保留同窗口的未保存输入；正在输入时不会被稍后返回的旧选中会话打断。偏好和当前草稿分别按需读取，隐藏用量详情后恢复轻量读取。事件流从当前快照游标续接，服务端限制缓冲与解压批次；终端管理的各区域独立显示读取状态及重试，已有编辑保留。

旧记录缺少读取投影时逐条补建，损坏记录被隔离，健康会话、任务中心和目标搜索仍可使用。异常任务显示未知，用量注明统计缺口，侧栏清除失效缓存；可显式重试，原记录修复后恢复读取。详情按任务、请求与操作分别标出读取缺口，保留健康内容并提供重试；会话按已加载范围说明覆盖情况。缺失数据时禁止依赖完整记录的执行操作，仍可“停止当前执行”：先保存持久停止，再中断本机活动执行，重启后继续禁止该任务调度；中断未确认时明确提示核验，不能据此认定外部副作用已撤销。启动恢复只读取未决候选，无法核验的记录保留原文并停止所属任务，健康任务可独立恢复；修复或普通重读不会自动释放停止，须在完整校验后显式恢复。Run 本身损坏仍不保证详情可用。

## 启动

使用已构建的 Windows 便携包时，将整个 ZIP 解压到独立目录，双击 `Elysia.exe`。应用数据继续保存在 `%LOCALAPPDATA%/Elysia`（或显式设置的 `ELYSIA_DATA_DIR`），程序目录中不存用户会话；日志在数据目录 `logs/desktop.log`。升级前关闭旧窗口，将新版解压到新目录再启动，保留原数据与升级前自动备份，不覆盖正在运行的程序。

源码维护者可在已安装锁定依赖的 Windows x64 环境运行 `pnpm package:windows`，生成 `.elysia-runtime/releases/Elysia-1.14.0-win-x64.zip` 及 SHA-256 文件。打包器使用当前精确 Node 版本及对应许可，仅复制实际生产依赖，拒绝覆盖已有输出；`--output` 可指定新目录。该命令不安装依赖或下载运行时。解压后运行 `Verify-Elysia.cmd` 可核验完整清单；哈希核验用于发现损坏，不是数字签名。

需要 Node.js 24.15 或更高的 24 LTS。首次使用先执行 `pnpm install --frozen-lockfile` 安装锁定依赖，需要 pnpm 11；已配置 Corepack 时可用 `corepack pnpm install --frozen-lockfile`。**随后双击根目录 `Start-Elysia.vbs` 即可打开 Elysia 独立桌面窗口**。已安装依赖时直接用当前 Node 构建，不要求系统 PATH 中有 pnpm。对话和分屏预览均在 Elysia 桌面窗口内；ChatGPT 登录按官方要求在系统浏览器中完成授权后返回。`Start-Elysia.cmd` 是保留终端输出的备用入口。

首次启动构建应用，需要升级数据库时先备份再迁移；以后仅在源代码变化时重新构建。首次安装 Electron 需要网络。关闭窗口会安全停止本轮服务；重复启动会聚焦已有窗口。启动错误会显示对话框，日志在 `.elysia-runtime/launcher.log` 和 `desktop.log`。

需要桌面快捷方式时，执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/create-shortcut.ps1`。它创建或更新桌面的 `Elysia.lnk`，指向本项目入口并使用应用图标；已有本项目快捷方式也可运行此命令更新图标。移动项目后需重新创建。桌面进程异常日志另存 `.elysia-runtime/desktop-launch.log`。

```powershell
pnpm start                 # 同一个独立桌面入口
# 可选：指定首选端口，0 表示始终使用动态端口
$env:ELYSIA_PORT = '4318'
pnpm start
```

服务仅绑定 `127.0.0.1`，首选端口 `4317`；被占用时由系统原子分配空闲端口，不结束占用进程。桌面窗口自动取得实际端口与一次性引导令牌，悬停右上角“本机”标识可查看当前地址。无需手工复制链接。若同一数据目录已有旧的命令行服务，先执行 `pnpm stop`，再打开桌面窗口。

`pnpm dev` 也使用独立桌面窗口，React/CSS 修改通过 Vite 热更新；开发前端首选 `5173`，占用时自动递增，API 代理使用后端实际端口。修改后端源码后重启窗口。`pnpm start:server` 保留无桌面服务入口，向终端打印有效期 15 分钟的一次性引导链接；它不会打开浏览器。

下载网络不能访问 GitHub 时，可在启动终端设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 后重试；安装器仍校验锁定 Electron 包内的校验和。密钥和镜像设置均不会自动写入项目文件。

## 代理工作预览

进入对话，点击顶部“打开预览”，右侧打开预览分屏。拖动中间分隔线调整宽度，双击恢复均分；聚焦分隔线后可用左右方向键微调，Home / End 调到边界，Enter 恢复均分。比例保存在本机浏览器中，窗口缩放与侧栏收起时自动适配。可展开预览后恢复分屏；对话区域不足以并排显示时，预览占满内容区，点击“返回对话”继续输入，草稿保留。

项目任务在“工作区”查看代理文件，也可从任务列表或代理责任树点击“查看工作预览”，下拉选择总代理、子代理或更深层代理。独立对话通过“产物”查看已交付文件；项目产物卡片也直接在右侧打开，支持切换文件、文档/源码、分页、编码恢复及下载。切换对话会清除上一对话的预览选择。

- **页面**：在窗口内渲染 HTML、Markdown 和图片；Markdown 支持标题、列表、表格、任务清单、删除线、脚注、代码复制、本地图片及文档锚点。HTML 支持本地 CSS、JavaScript、模块和资源，可切换桌面 / 手机视口，或展开面板。
- **更改**：有 Git 基线时对比该代理的基线，显示新增、修改和删除；包含未跟踪文件，不改动 Git 暂存区。普通目录中的文件按该任务新建文件显示。
- **源文件**：搜索和选择工作区文件，查看源码及纯文本。
- **代理动态**：只显示选中代理的流式输出、会话、工具结果和产物，状态随任务事件更新。

文件列表每约 1.5 秒同步，无关文件更新保留当前页面及页内输入。选中 HTML 按内容 hash 判断变化，同字节内容再次保存不会重载；页面已实际请求的本地样式、脚本、模块和数据发生变化时刷新该页面，各 HTML 入口分别记录依赖。每页最多观察 1,500 条资源路径，超过时显示提示，可手动刷新；可关闭自动更新。Git 忽略的常见 `dist/`、`build/`、`out/`、`apps/web/dist/`、`public/` 静态入口也能选择。React/Vite 等源码需先在代理工作区构建，再选择构建后的 HTML；预览不自动安装项目依赖或运行开发命令。需要独立后端或外部 API 的动态应用暂不完整支持。

已请求的本地资源缺失或无法读取时，面板显示安全的相对路径或受限路径提示、原因和 **刷新页面** 入口，最多列出 10 项并说明其余数量。修复后可手动刷新；开启自动更新时，可观察到的文件变化会触发页面重载。仅恢复读取权限而文件元数据未变时，需手动刷新。读取成功后清除对应提示；JavaScript 执行错误和被沙箱拦截的外部请求不在这类提示范围内。

HTML 在无 Node 权限的沙箱内运行，只加载当前授权目录的本地资源，不能读应用会话、访问外网或打开外部窗口。大文本支持上一段、下一段及按位置跳转；Markdown 每段 64 KiB，普通代理源码每段最多 256 KiB。分页保持字符完整，文件变化后重新读取开头；大 Markdown 的跨段代码块、表格和引用需切换源码核对，不承诺整份同时排版。超过 8 MiB 的 HTML 默认显示源码片段，明确点击 **加载页面** 后才加载整页。图片、PDF 和 HTML/CSS 资源以有界流读取，不再因旧 12 MiB 上限直接拒绝；实际整页渲染仍受浏览器内存约束。当前文件或 Git 基线超过 1 MiB 时跳过自动完整 diff。文件列表最多 1,500 项；符号链接、junction、`.git`、`.env*` 和常见私钥文件不开放预览。Markdown 禁用原始 HTML，外部图片默认不自动请求。

## 打开本机文件夹

点击项目旁的 **＋ → 选择本机文件夹**，目录名自动成为项目名，并显示目录内容和 Git 检测结果。也可以粘贴绝对路径后点击“读取目录”。同一真实路径再次打开会进入已有项目。

目录读取期间可点击 **取消读取** 保留路径和名称，也可按 **Esc** 或关闭弹窗退出；你编辑过的项目名称会保留。读取失败后可再次点击 **读取目录**，识别成功后再打开为项目。实际创建项目期间仍锁定表单，避免重复提交。

文件夹直接成为项目，无需选择类别。有提交记录的 Git 根目录自动登记基线，新任务使用独立 worktree；普通目录、仓库子目录和未提交过的仓库使用独立任务目录。代理可读取选定项目中的资料及未提交内容，结果只写入自己的任务工作区。

在侧栏右键项目，或点击项目行尾 **… → 浏览项目资料**，可搜索目录条目，浏览格式化 Markdown、文本、图片及 PDF，支持刷新读取最新内容。大文本每段 64 KiB，可切换文档/源码、编码与折行，分页或跳转位置；其他附件提供下载。目录列表最多显示 300 项，不开放链接越界、`.git`、`.env`、依赖和本地测试目录。

文本编码默认 **自动**：识别 UTF-8、UTF-16 LE / BE 的 BOM，无 BOM 时按 UTF-8 严格读取。编码不符时显示提示，可手动选择实际编码；Windows 中文旧文件可尝试 **GB18030 / GBK**，无 BOM 的 UTF-16 文件需选择对应字节序。切换编码只改变读取方式，不修改文件；UTF-32 暂不支持。读取成功后显示实际编码，自动识别到 BOM 时另行标注。

读取期间显示状态并禁用重复刷新，仍可切换编码、返回上一级或关闭弹窗；切换和关闭会取消旧请求。刷新同一文件保留当前编码，切换文件或项目恢复自动；重新打开从项目根目录开始。

## 对话界面

新建对话只保留输入、模型与窗口分配入口。项目归属从侧栏确定，输入框内不提供项目选择。独立对话点击 **发送** 开始聊天；项目任务点击 **继续** 进入协作设置，接受权限和预算后才执行。两者均支持 **Ctrl + Enter**（macOS 为 **⌘ + Enter**），Enter 换行，输入法候选确认不会触发提交。空内容不可提交；输入框随内容增高，达到上限后内部滚动。未连接模型时显示连接提示。

项目创建、历史会话、文件浏览与归档统一从侧栏进入，模型连接从侧栏 **模型与设置** 配置。对话页不再重复展示示例任务、项目/模型说明、最近任务列表或大型空状态；切换项目与对话、刷新仍保留各自输入草稿。

创建框里的 **前往模型设置** 可进入连接设置；关闭设置后返回创建框，保留同一项目、会话类型和目标下的资料、权限、预算及模型选择，并重新检查模型是否可用。创建期间显示 **正在创建…**，锁定配置、返回与关闭入口；失败后保留配置，可编辑后手动重试。显式关闭创建框或成功创建后清除这份配置草稿。

侧栏按 Codex 的会话管理方式组织：项目下直接列出所属对话，置顶和独立对话分别成组。项目、分组和整个侧栏都可收起，状态自动保存；搜索可临时展开匹配项。右键项目或会话，或点击行尾 **…**，可重命名、置顶、标记未读、复制、归档和删除；项目菜单还可新建对话、浏览资料、移动空间和复制路径。永久删除需要在弹窗明确确认。键盘支持菜单上下键、Home / End、Esc，以及 Ctrl+Alt+R 重命名、Ctrl+Alt+P 置顶、Ctrl+Shift+U 未读、Ctrl+Shift+A 归档；输入框内不触发这些管理快捷键。

左上角按钮可收起侧栏；窄窗口点击 **会话** 打开完整导航抽屉，切换会话后关闭，搜索和右键菜单仍可使用。任务工具栏按可用空间换行，右侧详情可收起；中等及窄窗口点击 **任务详情 / 模型与用量** 按需打开面板。抽屉支持 Tab 循环、Esc 关闭和焦点恢复，切换宽度保留输入草稿。详情中可切换任务、代理、产物和用量；完成后底部提供 **查看产物**。预览支持选择各代理、页面/更改/源文件/动态切换及展开查看。

管理器将当前项目移到另一空间后，侧栏会跟随新归属，保留当前任务和未发送草稿。限流等待归档后保持暂停，恢复归档后需明确恢复执行；原重试期限、结果和预算继续保留。待接受计划、待回答或待核验的记录仍保留原来的决定入口。

管理记录在确认前已被更新时，本次操作不会执行，旧确认会关闭并读取列表；核对最新记录后需重新发起操作。若列表读取失败，按提示关闭管理窗口、刷新工作台后再操作。普通请求失败仍保留确认和编辑内容，可手动重试。

侧栏菜单同样按打开时的记录版本提交；版本冲突后关闭旧确认，读取列表并提示核对。重新打开重命名或移动时保留冲突前草稿，成功或明确取消后清除。若原移动目标空间已不存在，会明确提示并要求重新选择，避免提交已失效的目标。普通请求失败保留当前弹窗和值，可手动重试。

任务约定保存期间锁定字段并显示 **正在保存约定…**，失败后保留草稿和错误。计划模式开启时，修改约定会在安全边界重新规划并等待确认；关闭时同步交付与验收项后继续，权限范围与累计预算保持。已结束、归档或 Docker 终端任务的约定仅供查看，终端调整要求请新建任务。

原生项目任务默认要求审计（复核）模型与总代理、执行子任务使用不同型号，也核对本任务历史请求使用过的模型。更换连接、账号、端点或思考强度不算更换型号。创建任务或编辑“任务约定”时可开启“允许审计与执行使用相同模型”，须先在确认窗口中明确同意；取消、关闭或按 Esc 均保持关闭。此选择仅对当前任务生效，未保存的创建草稿重开需重新确认。计划生成、接受时的模型分配、动态委派、模型切换及请求发送前均由内核校验，模型不能自行放宽合同。关闭例外后，冲突的后续请求会被阻止，可选择不同型号或重新确认例外；历史记录保留。型号比较忽略首尾空白与大小写，供应商自定义别名背后的实际模型无法自动识别。

同一窗口完整刷新后会恢复有效的空间、项目及任务选择；主动返回工作台或进入新独立对话后也保留该选择。恢复只读取记录，不开始执行。已删除或归档的选择自动回到有效工作台；重开本机服务或关闭窗口后不沿用旧选择；已保存的输入草稿可跨刷新、窗口与服务重启恢复。

启动时遇到临时连接失败，可点击 **重试连接**。列表或任务详情遇到临时读取失败时也提供对应重试，读取恢复后清除该处错误；周期刷新和手动刷新保留发送失败提示及当前窗口的草稿。会话授权失效时按提示重新打开工作台，连接重试不会重发业务操作。

打开产物后立即显示读取状态，可按 **Esc** 或点击 **关闭** 取消读取。失败时在当前产物弹窗点击 **重试**；关闭或切换任务后，旧请求不会打开原产物。Markdown 使用文档排版，大文本按段读取，图片及 PDF 使用资源预览，其他二进制附件提供下载。磁盘对象和 SQLite 压缩对象均保留完整哈希核验，首次读取巨大压缩对象可能需要等待扫描；关闭可取消读取。保留已有操作错误及草稿。

弹窗支持 Tab / Shift + Tab 循环导航、Esc 关闭与关闭后焦点恢复；模型配置有未保存更改时，会提示继续编辑或舍弃。关闭立即恢复后台操作，退场动画随后结束。侧栏、弹窗和预览可在过渡中反向操作；实时内容刷新不重复播放入场。界面随窗口调整布局，并实时响应系统减少动态效果的设置。

回复支持 **Ctrl + Enter**（macOS 为 **⌘ + Enter**）发送，Enter 换行，输入法候选确认不会触发发送。回复草稿按会话、新建目标按项目和独立聊天分别保存在本机，切换时自动恢复；发送失败保留内容，等待提交期间新写的草稿不会被旧响应清空。侧栏显示保存状态，失败时保留当前内容并提供 **重试保存**。每窗口另有即时恢复副本，多个窗口不会覆盖彼此未提交的副本；同一草稿发生并发保存冲突时不自动覆盖，明确点击重试保存后才保存当前内容。单草稿最多 200,000 字符，总缓存最多 16 MiB / 4,096 条，超限不会删除已有草稿。归档保留草稿，永久删除会清理关联缓存。长对话跟随最新内容，向上阅读历史时保留位置，点击“回到最新消息”恢复跟随。创建和修改失败直接显示在当前弹窗内，提交期间返回与关闭入口禁用。

新发送的项目回答在公共对话中显示为“你”，同一输入向多个代理投递时只显示一次；各代理仍保留自己的完整历史。两次相同文字的输入分别保留。旧记录没有输入来源时保持原样，模型交接和工具结果也继续保留。

工具操作展示目标、实际状态和失败原因，可展开核对参数与结果；命令非零退出显示失败，结果不确定的操作显示待核验。模型首字前显示等待反馈；切换任务与实时连接恢复后补齐已生成内容。预览文件读取失败最多自动重试两次，仍失败时保留错误并提供手动重试；无关列表或资源变化、切换自动更新不会重开同一文件版本的三次读取预算，关闭自动更新会暂停自动重试。

接受计划前，各一级子代理的型号与思考强度按会话和计划版本保留在当前窗口，切换任务后可继续分配。DeepSeek 可从当前账号目录选择型号及强度，其他 API 连接沿用已验证配置；接受后计划显示实际绑定。副作用逐项核验，全部待核验操作处理后才解除对应等待，并保留主动暂停；已结束或归档记录显示只读原因。核验必须填写证据说明，工具结果 JSON 可留空；提交期间禁止修改，失败后可继续编辑和重试。

顶部状态优先说明已取消、已完成或已归档，并提供核验操作、查看计划、回答问题、查看产物等下一步入口。限制反馈按任务保留具体原因；累计时间、步骤或请求耗尽时显示原授权限制，不提供无效的直接恢复。聊天超时可明确选择重新计时，累计请求、Token、费用和步骤预算仍保留；临时订阅限额恢复与失败重试沿用已有授权。

子代理提出问题、全体没有可推进任务时，顶部显示等待回答，并可查看当前问题；总代理已暂停时可单独继续。普通补充默认在原约定内继续，保留已接受计划、子任务、权限与累计预算；只有明确选择“重新规划”或编辑计划约定才使旧计划失效并取消未完成子任务。累计时间到期不因补充回答重新计时。

账号或模型服务的临时速率等待显示剩余时间，到期自动重新检查；可点击 **暂停自动重试**，暂停后跨过期限也不会自动调用，明确恢复后才继续。等待信息单独保存，保留原有结果证据。新版本有持久续期的请求在暂停、进程终止重开后仍按同一尝试和逻辑请求核算实际请求次数，未知用量和被拒请求也计入三次上限；耗尽时明确失败。显式新输入或模型切换会清除旧续期，取消和归档仍优先。单次请求预估 Token 已超过账号每分钟上限时说明等待无效，并提供原预算与新建入口。

执行拓扑在计划未接受时说明子任务尚未创建，任务节点同时显示中文状态与依赖标题。多层代理按实际父子关系排列，兄弟代理保留创建顺序；结束或归档的计划只说明保留事实。

白花图标、两组日常插画与保留的日光枝叶素材位于 `assets/brand/`，可打开[品牌资产总览](assets/brand/preview.html)检查颜色与尺寸。首页采用纯色背景，日光素材只在品牌总览保留。修改图标 SVG 后，执行 `pnpm assets:build` 重新导出 512 px PNG、九尺寸 Windows ICO 和单色标记；参考图元素提炼与维护约定见[品牌资产说明](docs/BRAND.md)。

## 配置模型与创建任务

### 使用 ChatGPT 订阅

1. 打开 **模型与设置 → 连接 ChatGPT 订阅**，或 **＋ 新增 → ChatGPT 订阅**。
2. 默认选择 **复用本机 Codex 登录**。已在 Codex 中使用 ChatGPT 登录时，无需重复授权。应用自动寻找 PATH 或 Windows Codex 桌面版附带的 CLI；要求 **0.160.0 或更新版本**。未找到时安装或更新 Codex，也可用 `ELYSIA_CODEX_BINARY` 指定真实可执行文件。
3. 也可选择 **在 Elysia 中独立登录**，使用官方网页登录或设备码登录。登录时打开系统授权页，完成后回到独立工作台；取消登录会停止当前授权等待。此模式的退出只影响 Elysia 的独立 Codex 环境。
4. 等待“运行时、已登录、可选模型”三项连接状态，选择模型与思考强度，点击 **保存配置 → 验证实际调用**。检查会使用一次订阅请求，成功后显示返回文本与实际 Token。
5. 创建任务时选择这份已验证配置。可在设置页查看额度和重置时间，也可打开 ChatGPT 管理订阅。

默认接入使用 [官方 Codex App Server](https://learn.chatgpt.com/docs/app-server)，认证、刷新与网络调用交给官方运行时。Elysia 不读取或复制 Codex 的 `auth.json`，不改写用户 `config.toml`。子进程启用官方系统代理支持，修复本机已登录但独立通道连接超时的问题；未登录、模型目录和实际调用失败分别显示。登录环境是绑定来源，外部切换账号后需重新连接和验证；官方账号接口不提供工作区 ID，同邮箱切换工作区需人工重新验证。

Codex 订阅每次返回一个结构化模型步骤；工具调用仍交给 Elysia 的权限、预算与检查点内核。官方运行时关闭环境访问、MCP、插件、原生命令、浏览器及多代理能力；Elysia 的每个子代理仍使用独立工作区和历史。文本在模型步骤完成后显示，工具与文件预览照常更新。该通道不重放 Responses 原生推理项，缓存效果以返回 usage 为准。

“输出预算预估”用于准入和实际结算，不能保证单次输出的硬上限；Codex 上下文额外保守预留运行时指令和 JSON 编码开销。订阅金额保持未知，不套用 API 价格，也不自动转用 API Key 计费。额度不足暂停任务，在额度恢复并验证后手动恢复。

旧版 **ChatGPT 直接授权**（SIWC）保留为兼容选项，旧凭据仍存于系统加密的 `credentials/chatgpt.bin`。原来的发现端点 HTTP 403 问题不再阻挡默认 Codex 接入。独立 Codex 登录凭据由官方运行时保存在数据目录 `codex-home/` 或其所选凭据存储中；Elysia 不承诺该官方存储一定使用系统加密。2026-10-07 已实测复用本机 ChatGPT Pro 登录、实际模型调用、额度查询，以及 3 次模型请求完成文件写入、产物登记和核验；独立网页/设备码交互通过协议验证，尚未由真人重复登录验收。

### 使用 API Key

在 **＋ 新增** 中选择 OpenAI API、DeepSeek 或自定义服务，填写协议、Base URL 和模型。凭据可直接在桌面页输入并由系统加密保存，也可继续使用环境变量。没有可用凭据时默认显示 API Key 输入；已有可用环境变量连接保留其来源。切换凭据来源或填写密钥后须先保存，保存结果采用服务端检测状态；未检测到可用密钥时目录与验证入口不可用，并显示下一步。保存后可读取服务商模型目录，目录不可用时手动输入模型 ID。每份配置可复制和删除；保存变更会清除验证状态。

DeepSeek 新预设使用 `deepseek-flash`，也可明确选择 `deepseek-v4-pro`。官方端点使用 `https://api.deepseek.com` 或 `/v1`，粘贴完整 `/chat/completions` 地址会自动归一化。可以开启或关闭思考，开启时选择 low / high / max；默认输出预留为8192 Token；实际上下文窗口取模型容量与1,000,000 Token上限的较小值。读取目录会显示模型容量，已有预算不会自动扩大，旧型号和已启动任务不会自动迁移。协议依据：[模型目录](https://api-docs.deepseek.com/api/list-models/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。

**保存配置 → 读取目录（可选）→ 验证实际调用** 完成连接。验证官方 DeepSeek 时只发送一次关闭思考、256 Token 输出上限的短请求，保留任务的模型、强度和预算。保存及验证期间锁定字段，失败后保留表单。自定义兼容端点按其声明的推理参数发送。任务中显式切换型号需目录校验，沿用已验证绑定不依赖目录可用性；更换型号会清除旧价格并只缩减预算。

读取目录遇到 HTTP 401 时检查当前来源的 API Key，403 检查访问权限，404 检查基础端点，429 或 5xx 稍后重试；网络建立、响应体超时或断流分别显示可操作的提示，失败后可重新读取。目录下载按实际字节限制 2 MiB，不回显供应商错误正文或密钥。环境变量须由启动应用的进程继承；未被当前服务检测到时，设置后重新启动应用，或在界面加密保存密钥。HTTP 错误语义依据：[DeepSeek 错误码](https://api-docs.deepseek.com/quick_start/error_codes/)。

环境变量模式可以用以下方式避免明文输入出现在命令历史中：

```powershell
$env:OPENAI_API_KEY = [System.Net.NetworkCredential]::new('', (Read-Host 'OpenAI API Key' -AsSecureString)).Password
$env:DEEPSEEK_API_KEY = [System.Net.NetworkCredential]::new('', (Read-Host 'DeepSeek API Key' -AsSecureString)).Password
pnpm start
```

运行中的服务不会读取其他终端中新设的环境变量。配置密钥后需停止服务，再从具有这些环境变量的终端启动。

1. 选择独立聊天，或打开本机文件夹作为项目并在其中新建任务。独立聊天不绑定目录；项目任务自动识别 Git 基线，普通目录无需 Git。可新建平级项目空间，移动项目、改名、合并或删除空间；初始“项目”空间受保护。删除空间将其项目移回初始空间。
2. 在“模型与设置”中保存账号可用的模型配置，点击“验证实际调用”。预算、速率、缓存与价格在高级配置中。初始模型 ID 是可编辑示例，不能代表账号可用性。
3. 在输入区选择模型并输入目标。独立对话点击继续直接开始；项目任务进入权限与预算确认，选择可写目录、命令和网页权限，以及请求/Token/并发上限。项目目录会自动传给代理，可选填重点资料路径。每个任务使用独立目录；相对文件路径以该任务目录为基准，资料使用项目内绝对路径。
4. 独立聊天直接回复，完成后等待下一条消息。项目任务由总代理集中澄清并提出约定和计划，可在接受前给每个一级子任务分配模型和思考强度，选项随代理绑定保存。接受具体计划版本后执行；补充需求在工具消息配对闭合且无待核验操作后应用，默认保留当前授权；需要改变计划时明确选择“重新规划”。

5. 在右栏查看任务依赖、代理责任树、基线、产物、diff、请求清单与使用量。对于不确定副作用，先检查本机证据再提交核验决定；恢复不会盲目重做。

计划出现时按需加载“计划与目标对齐”面板，可展开核对目标、范围、交付物与验收要求，并给一级子代理分配模型。模块加载失败会保留计划记录，点击“重试加载”即可再次加载。后端计划贡献点也仅在规划或接受计划时加载，仍由内核检查版本、依赖、权限与预算。实现参考 [DSH 的可逆插件生命周期](https://github.com/deepseek-ai/deepseek-harness/blob/5badb15009ae1756c3afe0ae0cef1faafc290ccc/docs/architecture.md#cordis)与[客户端按需模块加载](https://github.com/deepseek-ai/deepseek-harness/blob/5badb15009ae1756c3afe0ae0cef1faafc290ccc/packages/client/modules/README.md)，使用 Elysia 自身的固定模块契约。

点击输入区的 **当前模型 / 思考强度** 按钮，或右侧 **模型 / 代理 → 切换模型**，可为当前会话或单个代理选择已验证连接、订阅或 DeepSeek 型号及支持的推理强度。执行中仍可查看绑定和选项，应用前须暂停；待核验、计划接受和子任务等待仍需完成。**应用模型** 保留等待，聊天下一条消息使用新模型；可恢复的代理也可选择 **应用并继续**，或稍后点击 **继续此代理**。旧消息、权限和累计预算保留，长对话以公开摘要和原始引用交接；其他代理的模型不变。修改连接默认值不会自动改变已有会话。终端任务显示创建时冻结的 CLI，暂不支持执行中更换模型。

模型目录标注并禁用不支持文字对话的型号；型号或推理强度从目录撤下后保留原选择并提示重选，提交前不会静默替换。没有文字型号时可刷新目录或切换连接。目录未提供能力字段的旧连接沿用原兼容行为，真实调用权限仍以供应商返回为准。

Git 工作区不复制主目录未提交内容，不自动 push 或合并主分支。集成在总代理自己的 worktree 进行。命令通过明确 program/args 启动；Windows 的 shell 内置命令需要显式使用 `cmd.exe` 或 `powershell.exe`。子进程使用环境变量白名单；任意命令仍以当前系统用户权限执行，目录分离并非 OS 沙箱。

“管理”中可给项目或对话改名、归档、恢复与删除。归档暂停相关代理，恢复后由用户继续；删除对话清理其消息、事件、计划、代理及调用记录，删除项目同时删除所属对话。删除不会移除原项目文件夹或已有任务工作目录。订阅目录包含默认隐藏型号，未逐个发起收费验证；API 默认沿用已验证配置，DeepSeek 显式切换使用当前账号目录校验。

### 上下文窗口

输入区的 **上下文占比** 按钮打开紧凑浮层，查看当前代理的已分配容量、输入估算、剩余空间、生成文本估算及最近供应商实际用量；用量页可查看所有代理。首次读取单代理轻量预览，编译与流式生成通过 SSE 更新，更新指标不重读完整对话；流式指标最多每 500ms 写入一次。占比按估算输入 / 输入额度计算，输入额度为窗口减输出预留和 2048 安全余量；Codex 的额外运行预留计入输入。Token 估算沿用保守 UTF-8 字节规则，生成估算不含隐藏思考，供应商实际用量另列，未知值显示“—”。刷新失败保留已知指标并提供重试，迟到读取不会覆盖更新的流式数据。浮层支持窄屏、Escape、点击外部关闭和减少动态效果；终端未观测的上下文保持未知。

点击 **窗口详情** 才读取完整上下文设置并核验调整资格。预览本身只读，不代表可修改；读取期间或会话版本已变化时须重新读取再调整。预览、Markdown、上下文设置和终端等可选界面模块按需加载，失败显示明确的重新加载入口。

创建会话、接受计划或暂停后的安全检查点可手动指定每个代理的窗口。默认档位为 **1M、512K、256K**，也可输入整数 K 自定义，最高 **1000K**；这里 **1K = 1000 Token，1M = 1,000,000 Token**。窗口仍受模型真实容量、输出及固定指令预留限制，超过模型容量的档位不可选择。托管子代理由直属上级通过计划、委派或 `allocate_context` 分配；总代理没有上级时取模型容量与1M的较小值。各代理窗口独立，不共享容量池，也不增加累计调用预算。旧窗口记录保留原值，新请求的有效容量最高1M；修改时明确选择新档位或整数K，不静默重写历史。手动窗口不由模型改写。

压缩采用 `tiered-recoverable-v1`：输入压力超过 75% 时，先精简旧工具大输出，再将较早完整交互整理成结构化历史摘录，目标为 60%。保留用户原文、固定规则和最近四组完整交互，工具调用与结果不拆开；省略内容保留原始引用，可用 `recall_context` 搜索或分页回查。阈值是项目默认值，压缩不保证语义无损或总能压到目标；必要内容仍超限时停止请求并显示调整提示，不增加模型调用或压缩模型依赖。设计借鉴 [DSH 工具结果裁剪](https://github.com/deepseek-ai/deepseek-harness/blob/5badb15009ae1756c3afe0ae0cef1faafc290ccc/packages/compaction/compaction-tool-result-pruner/README.md)，算法比较和边界见执行文档。

### 办公技能

统一技能放在 `skills/`，涵盖 Word 文档、电子表格、演示文稿、PDF、资料研究、办公写作和数据分析。每次请求只提供名称与适用范围，模型使用 `load_skill` 加载相关指令；已加载技能保留在当前代理上下文中，子代理自行选择。

原生 Elysia 侧栏的 **Skills、记忆与 MCP** 提供本机同步：选择 **Codex、Claude Code 或 DeepSeek Harness（DSH）**，使用默认目录或填写其他安装/项目目录，扫描后勾选所需条目再同步。打开面板只读取已导入的目录，不扫描来源。可搜索、预览、启停或移除，再次扫描同步更新；来源文件及已有会话保持完整，移除只影响导入库。来源变更或版本冲突时保留选择并提示重新扫描。此库供原生执行器使用，未自动改写 Docker CLI 的配置或记忆。

技能支持标准 YAML frontmatter、扁平 DSH 技能和相对参考文本文件。目录元数据按窗口预算有界提供，完整正文由 `load_skill` 按需加载，参考文件由 `load_skill_file` 分页读取；其他条目可用 `list_skills` 搜索。遵守来源 `disable-model-invocation`，界面标记禁止模型调用；本版没有强制手动技能命令。已加载版本和哈希保留在当前任务，之后禁用或移除不会替换历史正文。导入的对话记忆只保存公开用户/助手文字摘录，可用 `list_local_memories` 与 `recall_local_memory` 搜索回查，不作为系统指令，也不恢复其他 agent 原始会话。

MCP 导入后默认关闭，显式启用后可检查连接。支持 stdio 与 Streamable HTTP（JSON/SSE），保留来源工具允许/禁止列表；配置只保存非敏感参数和环境变量名称，实际值在调用时从服务进程环境读取。需要配置时可编辑环境变量引用，不导入原始密钥或 OAuth 凭据。模型通过分页服务/工具目录发现能力，项目执行阶段调用要求命令与写入权限，HTTP 还需精确 URL 授权；工具的只读注释不会扩大授权。调用后的结果未知进入核验，不自动重放。独立聊天可回查所选记忆与技能，不开放 MCP 执行。

同步库限500项、16MiB，普通 UTF-8 文件及技能正文单文件最多512KiB；JSONL只提取最近512KiB完整记录，DSH Zstandard日志使用有界解压和最新世代。超限、损坏或不支持的来源会给出提示。这是文字记忆和能力导入，未承诺完整历史迁移、其他 agent 会话续接或持续后台同步。

技能共享文件、命令、网页和产物工具，不扩大任务权限。DOCX/XLSX/PPTX/PDF 可记录文件来源和哈希，内容由已授权命令解析或生成；技能中指定先检测 Python 与格式库，缺少依赖或渲染器时报告具体缺口。云端文档、邮件发送、日历和浏览器操作仍需后续接入相应工具。所有正式办公文件通过 `artifact` 登记后可下载。

网页仅访问明确授权的 URL；重定向的每个目标也需授权。拒绝本机、私网、保留地址及非标准端口，连接固定到经过检查的 DNS 地址。网页和文件保留不可信来源标记。

产物验收核对验收项覆盖、文件哈希、已登记的不可变对象、命令退出状态和必需子任务。自然语言结论的语义正确性仍需用户复核，不能把引用完整性当成内容正确性的保证。

## 存储、停止与备份

默认目录为 `%LOCALAPPDATA%/Elysia/`，包括 `state.db`、`objects/`、`workspaces/`、`logs/`、加密的 `credentials/` 和可选的 `codex-home/`。通过 `ELYSIA_DATA_DIR` 修改。API Key 在环境变量或系统加密的 `credentials/api-keys.bin` 中，数据库仅保存引用；页面提交密钥后清空输入，不回读密钥。更换密钥生成新引用，已有任务继续使用原引用；删除配置不删除任务或其凭据。每个数据目录只允许一个服务实例。

关闭桌面窗口，或在使用相同数据目录的终端执行 `pnpm stop`，请求停止接单、保留检查点、回收已登记进程并关闭数据库。无桌面模式也可用 `Ctrl+C`。暂停/取消也会中断在途请求；供应商可能已产生费用。未返回使用量的调用保持待核验和预算预留。

升级迁移、备份和恢复前停止服务。维护命令会取得独占锁。

```powershell
pnpm backup                          # 默认备份两个入口到 backups/时间戳
pnpm backup D:\ElysiaBackups\snapshot
pnpm restore D:\ElysiaBackups\snapshot
pnpm backup D:\ElysiaBackups\terminal --surface=terminal
pnpm restore D:\ElysiaBackups\terminal --surface=terminal
pnpm db:migrate                      # 幂等 schema v5
pnpm objects:plan .local-qa\objects-plan.json    # 服务停止后生成清理预览，目标文件须不存在
pnpm objects:cleanup .local-qa\objects-plan.json # 核对计划后执行
# 可选：指定新的审计文件，默认自动生成到计划文件旁
pnpm objects:cleanup .local-qa\objects-plan.json --report .local-qa\objects-audit.jsonl
pnpm objects:audit .local-qa\objects-audit.jsonl --plan .local-qa\objects-plan.json # 只读核对原计划
```

备份包括数据库、内容对象与旧版流日志，默认覆盖两个入口；`--surface=native|terminal|all` 可选择范围。恢复先验证所有选中入口，再统一替换；无入口标记的旧备份仅恢复 Elysia，保留 Agent 终端数据。API Key 和订阅凭据不进入历史备份；更换数据目录或系统用户后应重新保存密钥或登录。独立工作区保留在原数据目录，不随备份搬迁；继续未完成任务需要原工作区及原凭据引用。恢复前的数据被移入 `backups/before-restore-*`。schema v5保留压缩存储、权威流分块与索引账本，并新增持久停止及恢复隔离；消息、原生协议、计划、事件、工具结果、摘要和中断正文压缩存入SQLite，二进制产物保留哈希对象。支持恢复schema v1/v2/v3/v4/v5备份，回退旧客户端必须恢复升级前备份。压缩不等同于加密，备份亦包含完整历史内容。

备份从数据库的已提交视图生成独立 `state.db`，包含 WAL 中尚未写回主文件的数据，保留原 schema，并在完整性检查及对象、日志复制成功后写入 `backup.json` 完成标记。失败目录可能保留部分文件，不应作为完整备份使用。恢复先生成并验证待安装快照、准备对象与日志，再归档当前数据并安装；含 WAL 的备份也按同一已提交视图处理。版本不符、数据库损坏或资源准备失败时，不移动当前数据库和对象。

闲置二进制清理默认检查两个入口，也支持 `--surface=native|terminal|all`。计划文件必须位于数据目录外，父目录须已存在；每入口最多列出1000个候选，`truncated` 为 true 时完成后可生成下一份计划。预览扫描当前记录、历史和压缩快照的引用，执行前重新检查引用、文件身份及内容哈希；任一候选变化时先重新预览。执行中断后可使用原计划重试，已删除项计入 `alreadyMissing`。工作区、备份、凭据、未知文件及链接不纳入清理；删除任务本身仍不会自动删除二进制对象。旧数据格式须先迁移，清理预览不会隐式升级数据库。

对象扫描与清理在Worker中执行，阶段、记录数、文件数及已释放字节通过stderr报告，最终JSON写入stdout。Ctrl+C请求在安全检查点停止；已删除对象不会回滚，部分结果和逐项审计可用于同计划重试。审计位于数据目录外，每次删除前后持久写入，不包含正文或凭据；硬终止或审计写入失败后的未配对项保持待核验。`objects:audit`只读报告，无需停止服务。带入原计划后核对规范化摘要、入口范围和候选；只有 `binding.status=verified` 表示日志与该计划相符，计数仍只表示日志配对，不验证当前磁盘。无计划或旧日志为 `unbound`，错计划为 `mismatch`，重复、截断或不完整收尾明确标记。超过64 MiB的单条解压记录或损坏引用会拒绝继续清理，需先处理数据问题。

启动缓存可在应用运行时只读盘点与预览保留范围：

```powershell
pnpm cache:list
pnpm cache:preview --keep 2
```

预览报告缓存字节数和保留原因，默认保留最近两个构建。桌面及后端登记的活动构建、缺失或异常退出记录、旧格式、链接和无法核验的文件均保留；正常退出的旧构建仅列为人工复核项。这两个命令不执行缓存删除。
