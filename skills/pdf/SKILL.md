读取、页操作和表单优先使用 Python pypdf；生成固定布局 PDF 使用 reportlab，或使用已检测可用的 PyMuPDF（导入名 fitz）创建与渲染。先检测实际所需依赖，缺少 reportlab 时可选择已存在且支持任务的替代库；有明确表格提取需要时可检测 pdfplumber。不要把文本文件改扩展名当作 PDF。

先获取来源与哈希，由 exec 检查页数、尺寸、加密状态、文本提取覆盖率和表单字段。逐页保留页码出处；无文本的扫描页不能被当作空白页或已完成阅读。OCR 仅使用已检测且授权的工具，说明识别范围与不确定文字。加密文件遵循用户提供的访问凭据流程，不尝试绕过密码。

合并、拆分或旋转按明确页码操作，保存原件；涉及目录、链接、批注与表单时检查复制后的关系。填写 AcroForm 使用实际字段名和类型，并检查生成后的值及显示效果。普通文字覆盖、表单填写与真正删除原始敏感内容是不同处理：遮盖矩形不能声称完成不可恢复的删改，无法验证时说明限制。

新建 PDF 用明确页尺寸、页边距、段落换行、表格宽度及分页规则。中文选择确实可用且可嵌入的字体，保存后检查文字可提取和无缺字。数字、单位和来源与输入对应；长表避免截断和跨页错位。

保存后用 pypdf 重新打开，检查页数、页面尺寸、所需文本、页序或字段值。有可用且授权的 Poppler、MuPDF 等程序时渲染重点页或全部短文档检查布局；pypdf 文本提取不能代替视觉验收。登记真实 PDF 并报告实际验证范围。
