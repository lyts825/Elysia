使用 Python python-pptx（导入名 pptx），先检测依赖。旧式 PPT、受保护文件和不支持的嵌入对象需可用转换或其他适配流程，不能仅修改扩展名。

先用 read 获得输入来源与哈希，由 exec 检查页数、画布尺寸、各页布局、文本、表格、图表和图片。用户给定模板或上一期演示时，从副本修改并沿用主题、母版、尺寸、占位关系和视觉层级；旧事实须以新来源更新。修改既有页时保护未要求变动的内容与结构，避免重建整个文件造成母版丢失。

按受众和用途组织内容，每页保持一个清晰论点。标题、正文、图表、注释与引用有稳定的字号和位置；使用实际数据生成图表或表格，不以装饰性图片代替数值关系。图片保持宽高比。说明性备注仅在用户需要且流程能保留时添加。

python-pptx 可以读写结构，但不会渲染幻灯片或保证自动排版结果。以形状坐标、文本框尺寸、字号和可用字体检查越界与拥挤；复杂动画、SmartArt、原生媒体或未知对象先验证可保留性，不声称库已完整编辑其行为。

保存后重新打开检查页数、顺序、必需文本、表格数据、图表系列、图片和形状范围；用 zipfile 检查包完整性。已有授权渲染程序时导出 PDF 或图片，检查每页溢出、遮挡和阅读顺序；没有时报告内容与几何验证以及视觉缺口。通过 artifact 登记实际 PPTX，只有成功导出后才登记并声称附带 PDF。
