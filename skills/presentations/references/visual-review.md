# 演示文稿版面检查

先提取模板的画布比例、主题字体、颜色、母版、布局和常用间距。新内容尽量填入已有占位符；复制一页后检查图表、媒体、备注及关系文件，不假设外观相同就代表结构完整。

用页面目标决定信息层次。数据多时选择对比、趋势或构成中最能回答问题的一种图表；标题说明结论，来源和单位保持可读。保留必要的坐标基线与数据范围，不通过截断坐标夸大差异。

检查文本框边界、图片比例、标题与图例、表格跨行及页边留白。重叠可能是有意设计，自动几何检查只能定位疑点；文字在边界内也可能因字体替换而溢出。

可用时渲染缩略总览，再实际检查修改页和复杂页。修复后只复看受影响页面及相邻布局；不要为了密度统一而无条件缩小所有文字。仅打开 PPTX 或生成页面图片，不算已完成视觉核对。

保留可编辑文本、表格及图表，除非用户明确接受扁平图片。动画、SmartArt 和媒体的可保留性单独核对，输出中说明未验证的交互效果。
