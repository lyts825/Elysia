先识别数据口径、单位、时间范围、记录粒度和所需结论。标准库 csv、statistics、decimal 可完成简单分析；处理 XLSX 时组合 spreadsheets 并检测 openpyxl。只有分析规模或方法需要时才检测并使用 pandas、numpy 或 matplotlib，不默认这些库已存在。

读来源与哈希后由 exec 检查列、类型、记录数、缺失、重复和明显异常，按任务范围清洗。保留原始文件；记录实际采用的去重键、缺失处理和转换规则。不能把未知值当作零、重复行自动当作错误或无依据剔除异常值。金额用 decimal 或明确的精度策略，百分比说明分母。

按一致口径计算汇总、同比或占比；分组统计注意分类缺失与样本量，时间比较对齐区间。结论区分观测关系和因果推断；样本不足、口径差异和不完整期间须说明。图表用真实分析结果，单位、标签、时间和图例完整。

保存输出表格与必要报告，在交付物中简述来源、关键计算方法和处理规则。按数据风险进行必要核对：输入输出记录数、分组总和与整体一致、关键结果独立核算或抽样。需要图表时检测绘图库并生成实际资源，不能以描述代替文件。

用 read 或相应解析库重新检查输出，登记最终表格、报告或图表为 artifact。测试脚本和中间缓存仅在仍有用途时保留本地；正式交付物保留可复核的方法说明，不额外堆积重复报告。
