# 多表连接与缺失值

连接前写明左右表粒度、键和预期关系：一对一、一对多或多对多。检查键的唯一性、空值和类型；编号文本与数字不可未经判断混用。连接后核对行数、未匹配键和关键合计，防止一对多展开后重复计入金额。

去重先定义业务主键和保留规则。两行内容相同不一定代表同一事件；仅因金额异常也不能删除记录。保留原始值及清洗后的值，说明影响了多少记录。

分别处理“未采集”“不适用”“计算失败”和真实的零。均值、占比、增长率说明纳入分母的记录；全缺失组不返回看似有效的零。加权均值使用权重总和，汇总占比从分子和分母重新计算，避免简单平均各组比例。

检查日期解析、时区和期间边界，比较完整期间。样本结论注明样本量和选择方式；统计显著性不等于实际影响，更不证明因果。需要时对合理缺失处理方案做敏感性比较，保留结论的适用条件。
