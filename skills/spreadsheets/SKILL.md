XLSX 使用 Python openpyxl；CSV/TSV 优先用标准库 csv。先检测所需运行时与库。旧式 XLS 需要明确可用的解析或转换程序，不能直接用 openpyxl 打开。保留宏的请求需支持该格式的流程，不将普通 XLSX 保存声称为宏已保留。

先读来源元信息，使用 exec 列出 sheet、使用范围、标题行、公式、合并区域和关键格式，再针对相关范围工作。大表分批或 read_only 读取，不将全部内容塞入工具输出。现有模板保留 sheet 名、列序、单元格关系及用户指定格式；不在未确认范围内重排、删除或覆盖工作表。

分别用 data_only=False 检查公式和 data_only=True 检查已有缓存；空缓存不等于计算结果为零。openpyxl 不计算公式，标记 recalc 属性也不证明公式已执行。需要有效计算值时，使用已检测且授权的计算程序进行重算，或按用户需求交付明确注明未重算的公式文件与独立核算结果。

写入时区分文字、标识符、日期、数字、布尔与缺失值；身份证、编号和前导零保留为文字。金额和比例分别设置单位与格式。新增公式采用可理解的引用范围，保留既有公式及关系；不要根据内容自行把原本字面文字转换为公式。图表的分类、系列、单位和范围与数据对应。

CSV 检查编码、分隔符、换行和引号，字段内有逗号或换行时由 csv 模块处理；面向 Windows 中文 Excel 时可根据交付要求使用 utf-8-sig。CSV 无法保留多 sheet、公式缓存或图表，不承诺这些结构存在于 CSV 中。

保存后重新打开，核对 sheet、范围、关键单元格、公式、总数及数据类型，并检查输入输出记录数。核验引用未指向不存在的 sheet、输出未新增公式错误。必要时进行可用的渲染检查；结构检查与视觉检查分开报告。登记真实工作簿或文本表格为 artifact。
