使用 Python 的 python-docx（导入名 docx）处理 DOCX，依赖先按工作区指令检测。输入为旧式 DOC、受密码保护文件或其他不支持格式时，说明实际限制；转换仅使用已检测且授权的转换程序。不要把 Markdown 改扩展名当作 DOCX。

先通过 read 获取来源与哈希，再由 exec 解析段落、标题层级、表格、页眉页脚、节设置和内嵌资源。二进制 read 结果只提供元信息，解析原文件时保留出处。用户给定模板时从副本修改，沿用尺寸、边距、样式与章节关系；示例中的旧日期、人物和数据不能直接当作新任务事实。

用段落样式表达标题与正文，按内容使用表格、列表与分页。编辑局部文字时操作所需 run，避免整段 text 赋值清掉超链接、字段或混合样式。表格先检查合并单元格；页眉页脚检查 linked-to-previous 后再修改。图片使用保持比例的尺寸，不新增用户未要求的章节。

需要原生修订、评论、复杂字段或不可丢失的嵌入对象时，先确认当前库和保存流程的支持程度。python-docx 的普通替换不会生成 Word 修订；不能把对照表或颜色标注称为原生修订。不能可靠保留的内容应在修改前报告，或提供用户允许的替代产物。

保存新 DOCX 后重新用 python-docx 打开，核对必需文本、标题层级、表格尺寸、图片与节设置；用 zipfile 检查 ZIP 成员完整性。若已有可用且授权的 LibreOffice 或其他渲染程序，可转为 PDF 检查分页、截断和字体；没有渲染能力时将验证限定为结构与内容。登记真实 DOCX 为 artifact，并说明验证结论。
