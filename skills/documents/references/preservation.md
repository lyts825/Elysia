# DOCX 结构保留与审阅

先列出本次必须保留的结构。局部编辑不重建整个文档；用段落的 text 整体赋值可能丢失 run 格式、超链接及字段。替换跨 run 的词语时，先确认文本范围与格式边界，再在副本上验证。

页眉页脚可能继承上一节。修改前检查节边界和 linked-to-previous，避免影响前后章节。表格检查合并范围、重复表头、行跨页和单元格宽度；空白段落不是稳定分页方式。

目录、页码、交叉引用和编号具有字段或关系。python-docx 能写入 XML 不等于已计算这些字段，需支持的应用更新并另存，或注明尚未更新。检查图片、图表与嵌入对象的关系文件，包可打开也不保证对象完整。

原生修订应保留插入、删除及接受／拒绝语义。彩色标记和普通替换只是替代展示，不得称为 Word 跟踪修订。评论需有真实锚点；不伪造作者、日期或审阅身份。能力不明时先做小范围验证，再处理目标文档。

保存后对比受影响文本与结构；有渲染和图像读取能力时查看修改页、跨页边界及相邻页。保留实际检查范围，不能把 ZIP 完整性、正文提取和视觉验收合并为一个“通过”。
